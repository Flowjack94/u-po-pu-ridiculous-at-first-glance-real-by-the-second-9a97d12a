## The pitch

> We rent professional mourners to families who need a packed funeral, charging per mourner per hour, because nobody wants to be buried in front of empty pews.

One sentence, 157 characters. Bizarre at first glance — renting strangers to cry at a funeral — and a real business at second glance: grieving families pay per mourner per hour because nobody wants to be buried in front of empty pews.

## How to run

```sh
python3 main.py
```

This writes the entry sentence to `/output/entry.txt`. The program is
deterministic (stdlib only, no randomness, no time, no network) and
`validate_entry()` enforces the competition gate: one sentence, 1–200
characters, UTF-8, not only whitespace.
